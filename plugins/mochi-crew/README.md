# mochi-crew

The Mochi Crew mod for Claude Code: a pixel-art cat in a side pane that reacts to what your session
is really doing, with a crew of subagent kittens, XP and badges, a session meter, a file tree of
where Claude is working, a session badge, and Mochi Tutor, which quizzes you on the project and on
what Claude changed.

Install it in Claude Code:

```
/plugin marketplace add joeVenner/mochi-crew
/plugin install mochi-crew@mochi-crew
```

See the [main README](../../README.md) for screenshots and documentation.
